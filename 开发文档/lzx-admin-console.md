### 2.5 权限

通过「权限方案」控制各角色能做什么。系统方案为全站默认，被所有团队继承。权限按角色分层叠加：频道管理员、团队管理员、系统管理员均在「所有成员」基础上逐级追加权限。当前采用的三层权限配置如下：

- **所有成员**：编辑自己的消息（发布 300 秒内）、编辑附件（Edit Attachments）、消息表情回应、创建消息。
- **频道管理员**（在所有成员基础上追加，仅本频道生效）：管理公共频道设置与成员、管理私有频道设置与成员、删除消息（自己的和其他人的）、频道提及。
- **团队管理员**（在所有成员基础上追加，仅本团队生效）：添加团队成员、管理公共频道全部权限、管理私有频道全部权限（含创建与归档）、删除消息（自己的和其他人的）、频道提及。
- **Playbook 管理员**：保持默认。
- **系统管理员**：默认拥有全部权限，不受方案限制。

修改后点保存即时生效，配置存于角色（数据库），不写入 config.json。

## 第四章 环境

### 4.1 网页服务器

配置服务器网络入口的页面——站点 URL、监听地址端口、HTTPS/TLS、超时与负载等。**本页改动需重启服务器才生效，写入 config.json**。关键项：

- **站点 URL**：测试填 `http://localhost:8065`，正式部署改为实际 IP 或域名（需带端口，如 `http://192.168.1.100:8065`）。此为用户访问 Mattermost 使用的地址。
- **监听地址**：填 `:8065` 或 `0.0.0.0:8065`，让所有设备可访问；勿设为 `127.0.0.1:8065`（仅本机可访问，会导致侧边设备卡加载页）。此项指服务器绑定的「网卡地址 : 端口」，决定从哪块网卡收请求。
- **映射端口 80 到 443**：不建议开（仅监听 443 时可用，用反向代理时不推荐）。作用是将 HTTP 自动跳转到 HTTPS。
- **连接安全**：测试用「无」；正式部署上 HTTPS 推荐用 Nginx 反向代理处理加密，此时本项仍保持「无」。选项含义：「无」=明文 HTTP，「TLS」=启用 HTTPS 加密（需配证书文件与密钥）。
- **TLS 证书文件 / TLS 密钥文件**：用 Nginx 代理做 HTTPS 时无需填写；仅连接安全选「TLS」时才填对应的证书（公钥）与私钥文件路径。
- **使用 Let's Encrypt**：需自动申请免费 HTTPS 证书时才开启（须先开启「映射端口 80 到 443」），会自动申请并续期，证书缓存于 `./config/letsencrypt.cache`。
- 其余保持默认：读取/写入超时（300s）、最大有效负载（300000 字节，仅限 API 请求体，非文件上传）、网页服务器模式（gzip 压缩静态文件，推荐）、启用不安全的传出连接（否，避免中间人攻击风险）、托管资源路径（留空）。
- 页底按钮：「重新从磁盘载入配置」可在不重启下重读 config.json；「清除所有缓存」会短暂严重影响性能，平时勿用。

### 4.2 数据库

配置服务器与数据库的连接——驱动类型、连接字符串、连接池与各类超时等。**本页改动需重启服务器才生效，写入 config.json**。除数据源外基本全部保持默认。关键项：

- **驱动名**：保持 `postgres`（PostgreSQL，官方推荐），勿改。此为数据库类型。
- **数据源**：勿乱改，改错服务器无法启动。此为数据库连接字符串，含地址、账号、**密码**、库名（界面打码显示），安装时已配好，最敏感。
- 连接池与超时保持默认：最大空闲连接（50）、最大开放连接（100）、查询超时（30s）、分析查询超时（300s，供团队/站点统计的后台长查询用）、最大连接时限（1 小时）、最大连接空闲时间（5 分钟）、最小主题标签长度（3）。
- **SQL 语句记录**：生产保持「否」，否则日志暴涨且可能泄露数据。此为开发模式功能。
- **停用数据库搜索**：保持「否」；仅在已配置 Elasticsearch 等专用搜索引擎时才设「是」。
- **架构迁移**：只读，展示已应用的数据库表结构变更记录（含本项目自定义的 `iuin_` 系列迁移，属 IUIN 定制功能表）。
- **当前搜索后端**：只读，显示当前搜索方式，当前为 `database`（数据库自带搜索）。

### 4.3 文件存储

配置用户上传的文件/图片的存储方式。关键项：

- **文件存储系统**：内部部署用「本地文件系统」（存于服务器磁盘）；大规模/多机部署可选「Amazon S3」（云对象存储）。选定后仅对应字段可用。
- **本地存储目录**：保持默认（留空即 `./data/`）。此为本地模式下的文件存放目录。
- **最大文件大小**：默认 100MB 即可，调大会增加服务器内存压力与上传失败风险。此为单个附件上限。
- **启用按内容搜索文档 / 搜索 ZIP 内文档**：默认「否」；可按文档内文字内容搜索，开启影响性能且旧文档需数据迁移才搜得全。
- **Amazon S3 相关字段**（存储桶、路径前缀、区域、访问密钥 ID/密钥、终端节点、安全连接、调试、存储类别）：仅选 Amazon S3 时填写，本地部署忽略。

### 4.4 图片代理

让服务器代为加载消息中的外部 Markdown 图片，保护用户隐私（不暴露 IP 给外部图床）并缓存提速。可选功能，默认「否」。关键项：

- **启用图片代理**：默认「否」，不影响基本使用；如需保护用户隐私与提速可开「是」，按下方类型代理外部图片。
- **图片代理类型及远程配置**：开启后建议选「本地」（Mattermost 内置代理，零额外部署）；「atmos/camo」为需单独部署的外部代理服务，选它时才填「远程图片代理 URL / 选项」。

### 4.5 SMTP

配置服务器发送邮件用的邮件服务器（注册验证、找回密码、邮件邀请、通知等）。

五个字段（服务器、端口、用户名、密码、验证）是描述**同一个邮件服务的一套整体**，需一起匹配，都是服务商提供、直接照填的字段。当前 `localhost:10025` 为本地测试用；正式部署整套换成真实发信服务。

正式部署可选：普通邮箱开 SMTP（QQ/163/企业邮箱，零成本起步，但有每日发信量限制）或专业发信服务（阿里云邮件推送、SendGrid，有免费额度、更稳定，适合规模化）。

- **开启 SMTP 验证**：真实发信服务选「是」（需登录）；本地测试服务器选「否」。
- **连接安全**：按服务商给的端口选——465→TLS，587→STARTTLS，25→无。
- **跳过服务器证书验证**：默认「否」，除非邮件服务器用自签名证书。
- **启用安全警报**：Mattermost 有相关安全修复时邮件通知系统管理员，依赖邮件功能。正式部署建议「是」，测试阶段可「否」。

配置后可点页面「测试连接」验证是否发得通。

### 4.6 推送通知服务器

配置手机 App 接收推送通知的中转服务器（网页/桌面端通知不依赖此项）。关键项：

- **启动发送推送通知**：内部部署一般选「不发送」（关闭手机推送，网页/桌面端不受影响）。其他选项：「TPNS」用官方测试服务（仅测试，不可用于生产）；「手动输入」填自建 push proxy 地址。生产环境如需手机推送需付费 HPNS 或自建代理（涉及移动端重新打包，较复杂）。
- **推送通知服务器**：按上面所选方式填写中转服务器地址。
- **大频道通知阈值**：默认 1000 即可。此为独立保护设置，频道成员超过此数时禁用 @all/@here/@channel，防止海量通知拖垮服务器。

### 4.7 速率限制

限制 API 请求频率，防止服务器过载和第三方/恶意攻击刷接口。**本页改动需重启服务器才生效**。关键项：

- **启用限流**：总开关，正式公网部署建议开启，内部测试可关。
- **每秒最大查询 / 最大过载大小 / 内存存储大小**：保持默认 10 / 100 / 10000（每秒限 10 次、允许突发缓冲 100 个、跟踪上限 10000 个来源）。
- **限流粒度**：默认（下面两开关都关）时 10 次/秒是「全服务器共享」总额度，正常几人同时用就会挤爆，实用价值低，需靠下面开关改变粒度。
  - **根据远程地址改变限制（按 IP）**：每个 IP 独立算额度，某 IP 刷爆只限它自己，最常用。
  - **根据用户改变限制（按登录令牌）**：每个登录用户独立算额度，更精细，可区分同一 IP 下的不同账号。
  - **两者同时开**：IP 和用户两个维度**同时独立计算，任一超限即拦**（两道闸都要过），防护最全；但共享 IP 环境（公司/学校同出口 IP、NAT）下多人易一起撞 IP 关被误伤，此类环境宜只按用户或调大阈值。
  - **本项目建议**：内网部署开「按用户」、关「按 IP」。
- **通过 HTTP 头变化频率限制**：⚠️ 用 Nginx 反向代理并按 IP 限流时必须填 `X-Real-IP`（Amazon ELB 填 `X-Forwarded-For`），否则所有用户源 IP 都变成代理 IP，等于退回全局共享并互相误伤。

### 4.8 日志

控制服务器运行日志的输出位置、详细程度与格式，用于排查问题。多数改动需重启生效。

日志有两种输出方式（可独立开关，通常二选一即可）：

1. **输出到控制台**：即服务器命令行终端，建议**测试阶段**使用，方便实时查看。
2. **输出到文件**：写入日志目录下的 `mattermost.log`（满 100MB 自动归档为带日期的历史文件），建议**正式上线**使用，便于长期留存与事后排查。

其余配置项：

- **日志级别**（控制台/文件一样）：建议都设为「信息」（INFO）。详细程度三档：ERROR（仅错误）/ INFO 信息（错误+启动初始化信息）/ DEBUG 调试（开发用超详细）。
- **以 JSON 输出日志**（控制台/文件一样）：自行查看保持「否」（纯文本，便于人工阅读）；接入专业日志系统采集时才选「是」（JSON 机器可读）。
- **日志文件目录**：日志文件路径，建议保持默认（留空即 `./logs`；目录须存在且 Mattermost 有写权限）。
- **启用 Webhook 调试**：设为「是」，将 Webhook 调试信息写入日志，便于排查 Webhook 问题。
- **开启诊断和错误报告**：设为「否」，不向 Mattermost 官方上报错误与诊断信息以助改进产品。
- **高级日志**：JSON 配置的进阶日志规则（多目标输出、分级分流等），普通部署不用管，保持 `{}`。

### 4.9 会话时长

控制用户登录后多久需要重新登录，以及会话过期规则。

- **使用活动延长会话时长**：建议「是」——用户在用时会话自动续期，仅连续闲置超过下方时长才过期（滑动超时，即"闲置多久登出"）；「否」则从登录起到点强制过期，不管是否在用。
- **更改密码时终止会话**：建议「是」——改密后使该用户其他会话失效（本人主动改则当前会话不受影响），提升安全。
- **AD/LDAP 和邮件会话时长**：建议 1 小时（即闲置 1 小时后登出）。此为邮箱/LDAP 账号密码登录用户的闲置超时时长。
- **移动会话时长**：建议 1 小时。此为手机 App 用户的闲置超时时长。
- **SSO 会话时长**：建议 1 小时。此为单点登录（SAML/GitLab 等）用户的闲置超时时长。
- **会话缓存**：保持默认 10 分钟。此为会话在内存缓存的时长。

### 4.10 性能监视

让服务器暴露性能指标（CPU/内存/请求耗时/数据库等），供监控工具采集分析。可选运维功能，默认「否」。

⚠️ 采集能力是 Mattermost **自带**的，但从 8067 端口暴露的是**机器可读的原始指标数据**（Prometheus 格式），不是现成图表。要看曲线/仪表盘需**另行搭建** Prometheus（抓取存储）+ Grafana（可视化）。链路为：Mattermost(8067 出数据) → Prometheus → Grafana。无此监控系统时开了也无处查看，建议保持「否」。

- **开启性能监视**：无监控系统时保持「否」；有 Prometheus+Grafana 时才开。此为采集并暴露服务端性能指标的总开关。
- **启用客户端性能监控**：一般「否」，仅排查前端性能时才开。此项额外采集网页/桌面客户端性能（如页面加载耗时），数据量大。
- **客户端侧用户 id**：留空按默认采样；仅跟踪指定用户客户端指标时才填写（逗号分隔）。
- **监听地址**：保持默认 `:8067`（独立于主服务 8065），仅对内网监控系统开放，勿暴露公网。此为指标暴露的端口。

### 4.11 开发人员设置

含测试与调试功能。⚠️ 顶部明确警告：测试指令仅用于隔离的非生产环境，正式环境应关闭调试类开关。

- **启动测试指令**：生产必须「否」，测试阶段可临时开、用完关。开启后可用 `/test` 斜杠命令批量生成测试账号、数据与文字格式（改动需重启）。
- **开启开发者模式**：正式环境设「否」，测试阶段可开。开启后前端 JavaScript 报错会在页面顶端显示紫色警告条，便于开发排错。
- **启用客户端性能调试**：一般「否」，排查性能问题时按需开。开启后用户可在「设置 > 高级 > 性能调试」诊断自身性能问题（改动需重启）。
- **允许不受信任的内部连接到**：防 SSRF 的**内网地址白名单**，控制 Mattermost 可主动访问的内网地址（用于 Webhook、图片代理等场景，服务器代客户端发起请求）。
  - 目标为**外网地址**（如外部部署系统、钉钉/企业微信回调）：无需在此配置，直接可用。
  - 目标为**内网地址**：必须加入白名单才放行，且应**只填所需的具体地址**（如 `10.0.16.0/28`），切勿填 `10.0.0.0/8` 等大网段或全放行，把可被利用的范围降到最小。
  - 示例值（如 `Webhook.internal.example.com`）应删除，只保留真实需要的地址。

## 第五章 站点配置

### 5.1 自定义

配置登录页、菜单中展示给用户的名称、文字、链接、Logo 以及 App 下载引导。默认链接多指向 Mattermost 官网，内网 IUIN 定制版应统一清理为自有内容或留空隐藏。

- **网站名称 / 站点描述 / 启用自定义品牌 / 自定义品牌图片 / 自定义品牌文本**：无需在此配置，已改源码固定为一行输出。（原用于设置服务名、登录副标题及登录页自定义 Logo 与文字。）
- **启用询问社区链接**：「否」。开启后界面及帮助菜单会显示「询问社区」链接，跳转 Mattermost 官方社区；内网定制版用不上故关闭隐藏。
- **帮助链接 / 使用条款链接 / 隐私政策链接 / 关于链接**：全部留空。默认指向 Mattermost 官网，留空即隐藏对应链接，避免用户跳转到官网。
- **自定义忘记密码链接**：留空。留空时「忘记密码」走内置密码重置流程（配合 SMTP 发信）；仅当需跳转自建密码找回系统时才填。
- **报告问题**：选「隐藏链接」。此为帮助菜单「报告问题」入口的行为设置，四选一：
  - 默认链接：跳转 Mattermost 官方故障排查论坛（外网），内网无意义。
  - 自定义链接：跳转自填 URL（如内部工单/反馈页）。
  - 邮箱地址：点击打开邮件客户端，收件人预填指定支持邮箱。
  - 隐藏链接：从菜单移除该选项，最干净，内网首选。

### 5.9 公开链接

"公开文件链接"指为文件生成一个任何人（无需登录）用浏览器即可访问的链接，相当于把内部文件公开到网上，存在泄露风险。

## 第六章 认证

### 6.1 注册

配置新用户如何注册账号——是否允许创建账号、是否开放自助注册、能否邮件邀请。这是把控"谁能进入系统"的关键安全页，内网部署应收紧入口。

- **开启账号创建**：「是」。账号创建的总开关，保留建号能力。设「否」后邮箱、OpenID Connect、OAuth 2.0 等各种方式均无法创建新账号，点注册会报错。
- **启用开放服务器**：「否」（安全关键项）。设「是」后任何人无需邀请即可在本服务器自助注册（仅对邮箱注册有效），等于门户大开；设「否」后用户只能通过邀请或管理员创建加入，严禁任何人自助注册。
- **启用发送邮件邀请**：「否」。开启后用户可用邮件邀请他人加入（邀请默认 48 小时失效）。本项目邮件功能未启用，开了也发不出邀请邮件，且邀请入口收归管理员更可控，故关闭。

### 6.2 邮件

配置基于邮箱/密码的注册与登录方式。此处"邮箱"指用邮箱地址作为账号进行注册登录，与"发邮件通知"无关——即使未启用发信功能，用邮箱当账号登录仍可用。

- **启用使用邮箱创建账号**：「是」。允许用邮箱+密码注册账号。仅当强制所有人只能用 AD/LDAP、SAML、GitLab 等单点登录方式注册时才设「否」；本项目无 SSO，靠邮箱密码建号，必须开启。
- **需要邮箱验证**：「否」（硬约束）。开启后新账号须先收验证邮件、点链接验证邮箱才能登录。本项目邮件功能未启用，设「是」会导致新用户永远收不到验证邮件而无法登录，故必须关闭。
- **启用使用邮箱登录**：「是」。允许用户用邮箱+密码登录，基础登录方式。
- **启用使用用户名登录**：「是」。允许用户用用户名+密码登录（不影响 AD/LDAP 登录），用户名比邮箱好记，内网实用。

### 6.3 密码

配置密码强度规则与登录失败保护。

- **最小密码长度**：8。密码最少字符数（取值范围 5~72），8 位为常见安全底线。
- **密码要求**：勾选「至少一个小写字母」+「至少一个数字」两项（大写字母、符号两项不勾）。要求密码同时含字母和数字，配合 8 位长度安全性够用又便于记忆。
- **错误消息预览**：只读，无需配置。它会根据上面设置实时显示密码不合格时用户看到的提示文字，改动上面设置此处自动更新。
- **最大登录尝试次数**：5。用户连续输错密码 5 次后账号被锁定。⚠️ Mattermost 原生解锁走"邮件重置密码"，本项目邮件未启用，故被锁用户只能由管理员在后台（2.1 用户管理）重置密码/解锁。
- **启用忘记密码链接**：「否」。开启后登录页显示"忘记密码"链接，点击走邮件重置密码流程。本项目邮件未启用，显示了也收不到重置邮件、反而误导用户，密码找回统一走管理员后台重置，故关闭。

### 6.4 多重验证

多重验证（MFA）指登录时除密码外，还需输入手机验证器 App（如 Google Authenticator）生成的动态验证码，实现"密码 + 手机"双因素登录。仅对 AD/LDAP 或邮箱登录的账号有效，不依赖邮件/短信服务。

- **启用多重验证**：「否」。开启后仅是"允许"邮箱/LDAP 登录用户自行绑定验证器加强安全（不强制、不影响未绑定用户登录）。为求简单，本项目仅用密码登录，故关闭。

### 6.5 AD/LDAP、SAML 2.0、OpenID 连接、GitLab、访客访问 🔒

以上认证方式（AD/LDAP、SAML 2.0、OpenID 连接、GitLab、访客访问）均为企业版功能，本项目不使用，采用邮箱/用户名+密码登录。

### 7.1 插件管理

插件是运行在服务器上的扩展程序，用于集成第三方系统或扩展功能。⚠️ 插件本质是运行在服务器上的第三方代码，应控制来源。本项目要用插件，且基本使用市场中已开发好的成品插件。

- **启用插件**：「是」。插件系统总开关，开启后服务器方可加载和运行插件。
- **需要插件签名**：「是」。开启后禁止手动上传插件，只能从市场安装经签名验证的插件；插件在服务器启动时也会被验证，安全性更高。因主要使用市场成品插件，故开启。若日后需安装**自研或未签名**的插件，须临时改为「否」才能上传，装好后再改回「是」。
- **开启自动预包装插件**：「是」。服务器启动时自动检测并安装之前启用过的预包装（官方自带）插件，保持默认。
- **上传插件**：只读提示项（"在 config.json 中开启插件上传"）。是否允许上传由「需要插件签名」等控制，界面不直接填写。
- **启用市场**：「是」。开启后系统管理员可从插件市场浏览并安装插件——关闭则无从安装市场插件，故开启。
- **启用远程市场**：「是」。开启后市场会从配置的 URL 联网拉取最新插件列表；本项目服务器可访问外网，需联网获取市场上的成品插件，故开启（若为纯离线环境则应关闭）。
- **市场 URL**：默认，不用改。远程市场的地址，保持 Mattermost 官方默认市场即可。

## 第八章 集成

### 8.1 集成管理

配置 Webhook、斜杠命令、OAuth、访问令牌等对接外部系统的功能。⚠️ 这些功能开启即意味着"允许外部往系统发消息或允许外部程序访问系统"，用不到的一律关闭以最小化攻击面。本项目不做任何外部系统集成、不使用斜杠命令、无脚本或机器人，故除超时外全部关闭/留空。

- **启用传入 Webhook**：「否」。开启后允许外部系统（监控/Git/告警等）向 Mattermost 频道发消息（消息会强制标 BOT 标签防钓鱼）。无此需求故关闭。
- **启用传出 Webhook**：「否」。开启后当频道内出现特定消息时可自动通知外部系统（反方向）。无此需求故关闭。
- **启用对外 OAuth 连接**：「否」。开启后传出 Webhook 和斜杠命令可用 OAuth 与第三方服务认证。无此需求故关闭。
- **启用自定义斜杠命令**：「否」。开启后允许用户创建自定义 `/命令` 调用外部服务；不影响 Mattermost 内置命令（如 /call 始终可用）。不开放用户使用故关闭。
- **启动 OAuth 2.0 服务提供商**：「否」。开启后 Mattermost 可作为 OAuth 2.0 提供方，供外部应用用 Mattermost 账号授权。无此需求故关闭。
- **启用 OAuth 2.0 动态客户端注册**：「否」。开启后外部应用可自动注册为 OAuth 客户端，属较高风险项。无此需求故关闭。
- **DCR 重定向 URI 允许列表**：留空。仅在开启动态客户端注册时用于限制可注册的重定向 URI；上项已关，留空即可。
- **集成请求超时**：默认 `30` 秒。等待集成（斜杠命令、传出 Webhook、交互式消息/对话框）响应的超时秒数。
- **允许集成覆盖用户名**：「否」。开启后 Webhook/斜杠命令可自定义发消息显示的用户名，与覆盖头像同开会造成钓鱼伪装风险。
- **允许集成覆盖头像**：「否」。开启后 Webhook/斜杠命令可自定义发消息显示的头像，与覆盖用户名同开会造成钓鱼伪装风险。
- **开启个人访问令牌**：「否」。开启后用户可创建用于 API 认证的个人访问令牌，⚠️ 该令牌拥有账号完全访问权限、长期有效，泄露等同账号被盗。无 API 自动化需求故关闭。

### 8.2 机器人账号

机器人账号是专供集成/自动化使用的特殊身份，类似用户账号（有名字、头像、可发消息）但不能登录，通常配合 Webhook、API、插件对接外部系统。本项目无外部集成、无脚本机器人，故不启用。

- **开启机器人账号创建**：「否」。开启后系统管理员可在「集成 > 机器人账号」为集成创建机器人账号。无此需求故关闭。
- **当拥有者被停用时停用机器人账号**：「是」。安全联动项——当某用户被停用时，自动停用其名下的所有机器人账号，防止"人已离开、机器人仍在自动运行"的隐患。当前无机器人虽不生效，保留「是」以备日后开启时有此保护。

### 8.3 GIF

- **开启 GIF 选择器**：「否」。开启后用户可在表情选择器中搜索并发送 GIF 动图，该功能依赖外部第三方服务 Gfycat；内网访问不了外网、且 Gfycat 服务已于 2023 年关停，故关闭。

### 8.4 CORS

CORS（跨源资源共享）是一套"跨域放行"机制：浏览器默认禁止一个网站的 JS 调用另一个域名的接口，服务器可通过 CORS 声明允许哪些外部域名跨域调用自己的 API。本页控制"允许哪些外部网页用浏览器调用 Mattermost API"。⚠️ 配得越宽松暴露面越大；本项目无外部网页调用需求，全部收紧（不影响 Mattermost 自身前端，同源访问无需 CORS）。

- **允许来自以下跨源请求 URL**：留空（绝不填 `*`）。留空即不允许任何跨域；填 `*` 表示允许任何域名跨域访问，官方明确警告正式环境勿用。
- **CORS 公开的头**：留空。用于声明允许跨域请求方读取的响应头白名单，来源已留空时此项无意义。
- **CORS 允许证书**：「否」。开启后跨域请求可携带凭证（Cookie/登录令牌），风险更高。
- **CORS 调试**：「否」。开启后将 CORS 相关信息（带 `"source":"cors"` 标记）输出到日志，仅供开发对接调试用，正式环境勿开。

### 8.5 内嵌

"内嵌"指把 Mattermost 网页放进其他网站的 iframe 框架中显示。浏览器出于安全（防点击劫持 Clickjacking）默认禁止被嵌入，本页的白名单是"例外放行"名单。

- **框架上级**：留空。留空即禁止任何网站内嵌 Mattermost 网页（默认且最安全，防点击劫持）；如需被某些自有门户嵌入，才填其域名（空格分隔）。本项目无内嵌需求故留空，不影响 Mattermost 自身独立访问。

## 第十章 实验性

### 10.1 功能

本页多为实验性或性能微调项，默认值通常即最优，除个别项外一律保持默认。以下按控制台界面顺序排列。

- **连接元数据超时**：默认。等待抓取第三方链接元数据（用于链接预览）的毫秒数，链接预览已关，保持默认。
- **批量邮件缓存大小**：默认。每封批量邮件包含的最多通知数，邮件未启用，保持默认。
- **批量邮件间隔**：默认。批量任务检查新通知的频率（秒），间隔越大性能越好，邮件未启用，保持默认。
- **邮件登录按钮颜色**：留空。仅用于移动 App 邮箱登录按钮的白标配色（`#` 十六进制），无移动端定制故留空。
- **邮件登录按钮边框颜色**：留空。同上，移动 App 按钮边框配色。
- **邮件登录按钮文字颜色**：留空。同上，移动 App 按钮文字配色。
- **开启账号停用**：「否」。开启后用户可在设置中自助停用自己的账号（并触发确认邮件）。内网账号由管理员统一管理、不开放自助停用，且依赖邮件，故关闭。
- **开启自动回复**：「否」。开启后用户可设置自动私信回复（类似邮箱休假自动回复）。为保持简洁故关闭。
- **开启频道已读 WebSocket 消息**：「是」。控制 `channel_viewed` 事件是否发送，用于多设备同步未读状态。仅超大部署才考虑关闭换性能，本项目规模保持开启。
- **开启默认频道离开/加入系统消息**：「是」。控制是否在默认频道（广场）发布团队加入/离开系统消息，保持默认。
- **开启强化模式**：「否」。开启后以牺牲部分用户体验为代价强化安全，内网一般无需，保持关闭。
- **开启教程**：「是」。新用户首次登录后提示完成新手教程，便于快速上手。
- **开启入职流程**：「是」。向新用户展示入职引导步骤，便于快速上手。
- **开始用户输入中消息**：「是」。控制消息框下方是否显示"某某正在输入…"提示，仅大型部署才考虑关闭换性能，保持开启体验更好。
- **用户输入超时**：默认。发送"正在输入"WebSocket 事件的间隔毫秒，保持默认。
- **用户状态和个人资料获取轮询间隔**：默认。客户端定期刷新他人在线状态/资料的间隔毫秒，保持默认。
- **首要团队**：留空。填团队名后用户会被锁定为主要团队，无法加入其他团队或退出主团队。为保持灵活故留空。
- **在邮件通知中使用频道名**：「否」。控制邮件通知标题是否含频道名，邮件未启用不影响，保持默认。
- **用户离开状态超时**：默认。用户无操作多少秒后状态变为"离开"（默认约 5 分钟），保持默认。
- **禁用应用栏**：「否」。保留应用栏（频道右侧放集成图标的竖条），保持默认。
- **禁用浏览器重新获得焦点时的数据重新获取**：「否」。保持浏览器重新聚焦时刷新频道数据；仅拥有超大量频道/成员的用户才考虑设「是」换性能。
- **禁用唤醒重连处理程序**：「否」。保持电脑唤醒后自动重连刷新数据，保持默认体验。
- **频道自动补全延迟时间**：「否」。停用延迟即输入 `~` 后立即弹出频道补全；设「是」则需多输入几个字母才触发。保持立即补全。
- **YouTube 来源策略**：「否」。内网不使用 YouTube，保持默认（来源策略为 no-referrer，更保护隐私）。
